================================================================================
SUFFATCORE 2.0
ULTIMATE UI DESIGN SPECIFICATION
PAGE-BY-PAGE, CARD-BY-CARD, MENU-BY-MENU
================================================================================

FILE NAME: SUFFATCORE-UI-MASTER-DESIGN.txt
PURPOSE:
This is the complete UI design specification for the Suffat-ul Huffaz Digital
Ecosystem ERP/LMS/Portal platform.

It describes:

1. Global visual design language
2. Design tokens
3. Reusable components
4. Login/logout flow
5. Every role dashboard
6. Every sidebar menu
7. Every top menu
8. Every card layout
9. Every button behavior
10. Every page state
11. Desktop and mobile behavior
12. Frontend component structure

This file should be used by UI designers and frontend developers together.

================================================================================
SECTION 1: GLOBAL UI DESIGN LANGUAGE
================================================================================

The UI must feel:

- Premium
- Calm
- Secure
- Clean
- Mobile-first
- Easy for non-technical staff
- Suitable for classrooms and offices
- Dark and glassmorphic
- Apple-inspired but not overly decorative

Visual identity:

- Deep onyx background
- Translucent glass cards
- Thin glowing borders
- Soft blur
- Cyan primary accent
- Large readable KPI numbers
- Minimal icons
- Smooth transitions
- Touch-friendly buttons

The system has two separate UI zones:

1. ERP ZONE
   For staff/admin users:
   - SUPER_ADMIN
   - GLOBAL_JUNCTION
   - CENTER_ADMIN
   - NAZIM
   - USTAD

2. PORTAL ZONE
   For consumers:
   - STUDENT
   - PARENT

Important rule:

Students and Parents must never see ERP sidebars, ERP menus, finance pages,
staff pages, or admin controls.

Button behavior:

"Invalid login credentials"
"Your account is inactive."
"Unable to reach server."

export function Modal({ open, onClose, title, children, footer }) {
  if (!open) return null;

  return (
    <div fixed inset-0 z-50 flex items-center justify-center bg-black/60 p-4 backdrop-blur-sm>
      <div className="w-full max-w-lg rounded-3xl border border-white/10 bg-zinc-950 p-6 shadow-2xl">
        <div className="mb-4 flex items-center justify-between">
          <h2 className="text-lg font-bold text-white">{title}</h2>
          <button onClick={onClose} className="text-zinc-400 hover:text-white">
            X
          </button>
        </div>

        <div>{children}</div>

        {footer && (
          <div className="mt-6 flex justify-end gap-3">
            {footer}
          </div>
        )}
      </div>
    </div>
  );
}
